## 关键诊断

1. 限量重接确实执行了 5 次一删一加换边，但四个视频的官方 edge TP/FP/FN 和 division TP/FP/FN 全部保持不变。这些换边在官方 7 微米节点匹配后的可评分拓扑中等价，不能视为有效提升。
2. `veto_only` 检查了保守选出的 safe-div 事件，但没有删除任何边，因此结果与关闭 FOCUS3D 完全相同。
3. 广泛重接将普通边 TP 从 2189 降至 2175，FP 从 97 增至 120，FN 从 104 增至 118；同时新增 7 个错误分裂，真实分裂 TP 仍为 1。其官方 CV 比基线下降 0.026108。
4. 广泛重接在四个视频中的三个明显变差；剩余一个视频普通 edge Jaccard 不变，只因节点数量惩罚的微小变化使 adjusted edge Jaccard 增加约 0.000114，不能抵消整体损失。
5. 所有策略的真实分裂召回仍为 1/5。当前接入只在既有节点之间换边，无法恢复缺失的 daughter 节点或生成新的分裂候选，因此没有解决 candidate recall 瓶颈。

## 结论

当前 FOCUS3D 三维掩膜作为局部换边或 safe-div 否决证据，没有带来可测量的官方 CV 增益；扩大作用范围会显著破坏普通轨迹并制造分裂误报。停止继续调换边阈值。若继续使用 FOCUS3D，应另开实验验证“未匹配高质量实例是否能补充缺失节点/子细胞”，且先测节点候选召回和精确率，再允许进入轨迹图。
