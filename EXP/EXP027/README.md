# EXP027：FOCUS3D 候选的结构约束选择诊断

EXP026 证明 `16/20µm` 的父子/双子几何门可以把 18 个开发事件的完整三元组召回从 `14/18` 提高到 `18/18`，但候选数增加到 1,708。EXP027 测试第一版全局选择层能否通过节点冲突约束和 FOCUS-only 激活代价控制这次膨胀。

固定比较：

- Pilkwang-only 节点，几何代价；
- Pilkwang 与 FOCUS3D 联合节点，FOCUS-only 激活代价 `0/2/4/8/12µm`；

候选代价为 `父子距离 + 0.5 × 双子间距 + 激活代价 × FOCUS-only 节点数`。选择器强制：每个父节点最多一个分裂、每个 daughter 最多一个入分裂、每个标注事件最多一个候选。它是确定性的贪心集合打包诊断，不是生产 ILP。

本实验使用同一批 12 个视频/18 个真实分裂事件，使用 EXP026 的 `16/20µm` 候选门；不使用真实标签参与选择，不加入未验证的轮廓权重，不生成最终图、官方 CV 或 `submission.csv`。
