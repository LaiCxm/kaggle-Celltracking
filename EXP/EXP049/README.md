# EXP049：ILP 后分裂候选结构晋级

EXP048 证明关闭基线可逐字节复现，并确认 EXP046 的低分第二边虽然进入候选，却在 ILP 后仍全部退化为单出边。EXP049 不再让低分边参与普通 continuation 竞争，而是保存模型每个父节点的第一、第二候选，在 ILP 和原有后处理之后，以严格结构约束决定是否补成分裂叉。

固定条件包括：第一候选概率至少 0.60、第二候选至少 0.18、两条父子边均不超过 7 微米、双子间距 8–14 微米、距离不对称度不超过 0.60、下一帧分离增量至少 2.25 微米、DeepCenter 通过、每帧至多一个。仅扫描方向余弦阈值 `-0.90/-0.75/-0.60`，并与完全关闭分支在同一确定性预测图上使用官方 patched scorer 比较。
