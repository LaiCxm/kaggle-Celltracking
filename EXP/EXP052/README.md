# EXP052：ILP 后分裂候选 Top-3 延迟晋级

EXP049 的 `cos060` 在四个完整验证视频上将官方 patched scorer 提升到
`0.9614675166`，但它只保存每个父节点的前两条模型边。本实验保持 EXP049
的冻结权重、确定性配置、结构门、DeepCenter veto、每帧最多一个和总数最多
64 全部不变，只增加第三条模型边作为延迟备用候选。

每个父节点继续保存 EXP049 兼容的五列行：

- `proposals`：第一边 + rank-2 备用边；
- `proposals_rank3`：第一边 + rank-3 备用边。

先完整执行原 Top-2 `cos060` 晋级。只有 rank-2 没有晋级的父节点，且该帧
尚未消耗唯一晋级名额时，才对 rank-3 行重复同一结构门。官方 CV 内核只运行
`off`、原 Top-2 `exp049_cos060`、新 `exp052_top3_cos060` 三个分支，不产生
测试集提交文件。
