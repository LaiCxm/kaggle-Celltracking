# EXP030 结果分析

## 实验性质

EXP030 是候选层诊断，不是完整推理管线，也没有生成 `submission.csv`，没有运行官方 patched scorer。因此本轮没有正式 CV，也没有 LB 分数，不能与 EXP018-A 的 0.946 或 EXP010 的 0.942 直接比较。

本轮固定 Pilkwang 和 FOCUS3D 原始权重，固定父体 16 微米、daughter 20 微米的联合候选门，在 24 个训练视频的 31 个已标注 division 事件上做按视频留出的候选排序。并集候选共 1,967 个，每个事件恰有一个正候选，正候选召回为 31/31；所以本轮测的是“候选进入后能否排到前面”，不是候选召回。

## 主要结果

| 排序臂 | Top-1 | Top-3 | Top-5 | 结构选择命中 |
|---|---:|---:|---:|---:|
| 固定几何 | 13/31 = 41.9% | 19/31 = 61.3% | 22/31 = 71.0% | 13/31 |
| 三特征逻辑回归 | 14/31 = 45.2% | 22/31 = 71.0% | 26/31 = 83.9% | 14/31 |
| 丰富 FOCUS3D 特征逻辑回归 | **17/31 = 54.8%** | **23/31 = 74.2%** | 25/31 = 80.6% | **17/31** |
| 丰富特征视频内置乱 | 10/31 = 32.3% | 22/31 = 71.0% | 26/31 = 83.9% | 10/31 |
| 丰富特征随机森林 | 14/31 = 45.2% | 21/31 = 67.7% | 25/31 = 80.6% | 14/31 |

丰富逻辑回归相对三特征基线增加 3 个 Top-1 事件，表面提升 9.7 个百分点；相对固定几何增加 4 个事件，提升 12.9 个百分点。按同一事件配对，丰富逻辑回归相对三特征基线为 5 胜、24 平、2 负；提升主要来自 3 个视频，另有 1 个视频损失 1 个事件。按视频做等权 bootstrap，Top-1 事件差的 95% 区间为 `[-0.0417, 0.3750]` 个事件/视频，跨过零，样本还不足以证明稳定泛化。

与视频内置乱结果相比，丰富逻辑回归为 8 胜、22 平、1 负，净多 7 个 Top-1 事件。这个结果说明 FOCUS 派生列可能含有排序信号，但不能直接解释为“轮廓掩膜本身带来 7 个收益”。当前置乱列集合同时包含：

- 真正的掩膜几何量：体积平衡、体积守恒、父体与 daughter 联合重叠及覆盖率；
- FOCUS 实例质量；
- daughter 间距归一化分数；
- `focus_instance_count`、`consensus_count` 这类来源组成统计。

因此该对照破坏的是“FOCUS 派生证据与候选真值的联合关系”，不是纯粹的轮廓几何置乱。后续若要声称轮廓本身有效，必须把纯掩膜几何、实例质量、来源组成分开做消融。

## 缺失值与偏差检查

在 1,967 个并集候选中，所有 31 个正候选都存在。特征缺失比例为：

- 体积平衡：22.9%；
- 父体与 daughter 联合重叠、父体覆盖、daughter 覆盖、体积守恒：32.7%；
- 平均 FOCUS 实例质量：1.2%；
- 距离和来源计数：无缺失。

缺失比例在正候选中略低于负候选。Notebook 使用每个留出折训练集的中位数填补，并额外加入缺失指示列，所以排序器可能利用“有没有可用 FOCUS 实例”这一事实，而不只是利用掩膜形状。正候选中三节点均为 consensus 的比例约为 74.2%，负候选约为 39.8%；这进一步说明来源组成与标签有较强关联，不能和轮廓几何混为一谈。

## 结论与边界

EXP030 给出了一个有价值但尚未可上线的信号：在候选已完整进入池子的前提下，加入 FOCUS3D 派生列后，逻辑回归的 Top-1 从 14/31 增至 17/31。由于视频级区间跨零、样本量只有 31 个事件，而且置乱对照不是纯掩膜对照，本轮只能记为“候选排序方向值得继续审计”，不能记为生产收益，也不能据此推送完整测试集。

下一步应先做低成本、可解释的分组消融：

1. 仅加入五个父体/daughter 掩膜几何量；
2. 在此基础上单独加入 FOCUS 实例质量；
3. 最后单独加入来源组成统计；
4. 全部保持按视频留出，并对每个版本做视频级 bootstrap；
5. 只有在独立分组仍稳定优于三特征基线后，才把排序器接入完整图和官方 scorer。
