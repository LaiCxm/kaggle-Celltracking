# EXP030：加入 FOCUS3D 三维掩膜证据的 division 候选排序

EXP029 在 24 个视频上显示，只有距离和 FOCUS-only 数量的排序器相对几何基线只增加 1 个正确事件。本轮固定相同的 `16/20µm` 高召回候选门，真正加入 FOCUS3D 的三维掩膜派生特征：父体与 daughter 联合重叠、父体覆盖、daughter 覆盖、体积守恒、daughter 体积平衡、实例质量和来源组成。

比较五个排序臂：几何基线、三特征逻辑回归、掩膜增强逻辑回归、掩膜特征视频内置乱对照、受限随机森林。全部按视频留出；Pilkwang 和 FOCUS3D 权重冻结。

本实验不生成 `submission.csv`，不运行官方 scorer。只有当真实掩膜增强优于三特征基线且掩膜置乱后优势消失，才认为 FOCUS3D 轮廓提供了可利用的排序信息。
