# EXP025：FOCUS3D 分裂候选证据校准

本实验承接 EXP021 的候选层。根据用户指示，即使 EXP024 未发现 FOCUS3D 独有标签中心，FOCUS-only 实例仍作为探索性候选进入候选池；本实验不据此晋级生产方案。

目标是在进入全局选择器前，判断 FOCUS3D 的真实三维轮廓是否能改善正确分裂三元组的候选排名。固定比较四组：

1. 仅距离几何；
2. 距离加质心/体积；
3. 距离、体积加真实轮廓；
4. 与第 3 组相同，但在视频内打乱轮廓特征。

采用按视频留一的逻辑回归，只报告候选层的 OOF AUC、平均精确率、Top-1/3/5 事件召回和倒数排名均值。只有真实轮廓优于质心/体积，且轮廓置乱后优势消失，才能证明增益来自轮廓。

该实验不生成最终图，不运行官方图评分，不生成 `submission.csv`。
