# EXP031：FOCUS3D 证据分组消融

本实验承接 EXP030，固定相同的 24 个视频、31 个 division 事件和 `16/20µm` 联合候选门。Pilkwang 与 FOCUS3D 权重均冻结，不生成竞赛提交文件。

本轮将 EXP030 的混合特征拆成四组：

- 纯掩膜几何：体积平衡、体积守恒、父体与 daughter 联合重叠及覆盖率；
- FOCUS 实例质量：平均实例置信度；
- 来源组成：FOCUS 实例数和 consensus 节点数；
- daughter 间距归一化分数：保留在完整特征组中，不混入纯掩膜组。

所有逻辑回归均按视频留出。除事件 Top-k 外，额外报告按视频聚类的配对 bootstrap，比较每个分组相对于三特征基线的 Top-1 差异。
