# EXP024：Pilkwang 与 FOCUS3D 跨视频实例召回泛化审计

本实验在 EXP016/EXP023 已检查视频之外，按胚胎前缀分层选择 12 个视频，再按视频轮转、沿时间轴分散抽帧，累计到约 500 个已标注细胞即停止。不会对全部训练视频运行推理。

GT 是稀疏标注，因此主要指标是已标注节点召回率、定位距离和成对互补命中，未匹配预测不作为假阳性。主比较单位是视频：对每个视频计算 `Pilkwang 召回率 - FOCUS3D 召回率`，再做固定随机种子的 10000 次视频级自助抽样，报告均值和 95% 置信区间。

本实验不运行连接边、ILP、分裂后处理或官方图评分，也不生成 `submission.csv`。
