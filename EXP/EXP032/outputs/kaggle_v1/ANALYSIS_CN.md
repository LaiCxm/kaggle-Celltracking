# EXP032 结果分析

EXP032 将 EXP031 的候选门、冻结模型、特征分组和按视频留出方法扩展到 48 个含真实分裂的视频。该实验是候选排序诊断，不生成提交文件，也没有运行官方评分器。

## 数据完整性

- 48 个视频，共 71 个真实分裂事件。
- 70 个事件的父节点和两个子节点形成了正确候选三元组。
- `6bba_7f87b3d8:769` 缺少第二个子节点；Pilkwang 与 FOCUS3D 都没有检出，因此任何排序器都无法恢复该事件。
- 联合候选池共有 4,485 个三元组。

## 排序结果

| 方法 | Top-1 | Top-3 | Top-5 |
|---|---:|---:|---:|
| 固定几何 | 38/70 | 53/70 | 58/70 |
| 三特征逻辑回归 | 48/70 | 59/70 | 64/70 |
| 三特征 + FOCUS3D 掩膜几何 | **49/70** | **61/70** | 63/70 |
| 掩膜几何 + 实例质量 | 48/70 | 60/70 | 62/70 |
| 掩膜几何 + 来源组成 | 48/70 | 61/70 | 63/70 |
| 全部特征 | 48/70 | 60/70 | 62/70 |
| 掩膜几何置乱 | 45/70 | 61/70 | 63/70 |

## 结论

纯掩膜几何相对三特征逻辑回归为 3 个视频增加、43 个视频不变、2 个视频减少，Top-1 净增加 1 个事件。视频级配对 bootstrap 的 95% 区间为 `[-0.0625, 0.1042]` 个事件/视频，跨过零；`44b6` 前缀两者均为 `17/24`，`6bba` 前缀由 `31/46` 提升到 `32/46`。

因此，FOCUS3D 轮廓几何存在微弱且可重复的候选排序信号，但扩大样本后收益仅为 `+1/70`，不能证明它能稳定改善完整追踪图。实例质量、来源组成和完整丰富特征均没有额外收益，不应继续堆叠。下一步应去掉“已知真实父节点”的提示，在所有可能父节点之间验证真实分裂能否被发现。
