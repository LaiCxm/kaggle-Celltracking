# EXP045 分析

## 结果

四个完整训练视频包含 5 个 GT division、10 条真实 parent→daughter 边。结果为：

| 状态 | 数量 |
|---|---:|
| 最终进入候选池 | 6 |
| 仅在阈值前 top-k 中、但未通过概率阈值 | 4 |
| 因 source budget 拒绝 | 0 |
| 因 target budget 拒绝 | 0 |

四条缺失边的原始概率为 `0.18795、0.35614、0.01286、0.40623`。因此 EXP044 中的 `6/10` 不是预算截断造成的，当前可见瓶颈是边模型对第二 daughter 的原始置信度不足。

## 解释

- `0.35614` 和 `0.40623` 是较接近阈值的第二边，适合做受限召回测试；
- `0.18795` 需要更明显的局部放宽；
- `0.01286` 同时处于 source rank 8、target rank 4，不能仅凭“第二边”规则安全恢复；
- 端点本身均已被检测，问题不在中心节点召回。

## 决策

不降低全图候选阈值，也不修改 source/target 总预算。EXP046 只对第一高边≥`0.60`、第二高边≥`0.18`、物理距离≤`14µm`的 source 额外保留第二出边，并用官方 patched scorer 验证普通 edge 是否退化、division 是否增加。

本实验是候选边诊断，不是正式 CV/LB；正式评分结果等待 EXP046 官方 CV。
