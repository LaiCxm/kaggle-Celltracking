# EXP029：扩大视频面板的 division 候选排序训练

EXP028 在 12 个视频、18 个事件上显示，按视频留出的三特征逻辑回归能把结构选择命中从 `5/18` 提高到 `8/18`。EXP029 将同一候选生成和排序问题扩大到 24 个含 division 的训练视频，每个视频最多抽取 2 个事件，检验这个提升是否只是小面板现象。

本实验只训练轻量级候选排序器，不重新训练 Pilkwang 或 FOCUS3D。两套原模型权重冻结。候选池仍使用 `16/20µm`，排序特征为父子距离、双子距离和 FOCUS-only 节点数量；逻辑回归按视频留出，结构选择施加父唯一、daughter 唯一和事件唯一约束。

本实验是候选层诊断，不生成 `submission.csv`，不运行官方 scorer，也不改变 EXP018-A 的 `0.946` 生产回退。
