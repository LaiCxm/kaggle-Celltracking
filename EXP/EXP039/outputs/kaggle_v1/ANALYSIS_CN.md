# EXP039 中文分析与三轮路线复盘

## 1. 实验口径

EXP039 是候选层诊断，不是完整推理，也没有生成 `submission.csv`。实验固定 EXP038 的 OOF 排序分数，只过滤候选门限，比较：

- `parent_gate`：parent 到 daughter 的距离上限；
- `daughter_gate`：两个 daughter 之间的距离上限；
- `candidate_base`：基础排序；
- `continuation_conflict`：加入 continuation/parent 竞争证据的排序。

共有 31 个含真实 division 的事件。`top1_all_recall` 将正确三元组被门限过滤掉的事件计为失败，因此它同时反映候选保留和排序质量。面板不含无 division transition，也没有官方 patched scorer。

## 2. 主要结果

最大 `16/20 µm` 候选池有 `686,116` 个三元组，真实三元组召回 `31/31`，但：

- 基础排序 Top-1 只有 `2/31`；
- continuation 竞争排序 Top-1 只有 `3/31`。

把 daughter-daughter 门限收紧到 `14 µm` 后，结果发生明显变化：

| 排序 | 门限 | 候选数 | 相对最大池 | 真实候选召回 | Top-1（全部事件） | Top-1（候选存在事件） |
|---|---:|---:|---:|---:|---:|---:|
| 基础 | `10/14 µm` | 53,201 | 7.75% | 22/31 = 71.0% | 6/31 = 19.4% | 6/22 = 27.3% |
| 基础 | `12/14 µm` | 132,869 | 19.37% | 26/31 = 83.9% | 6/31 = 19.4% | 6/26 = 23.1% |
| 基础 | `14/14 µm` | 237,646 | 34.64% | 28/31 = 90.3% | 6/31 = 19.4% | 6/28 = 21.4% |
| 基础 | `16/14 µm` | 364,096 | 53.07% | 29/31 = 93.5% | 6/31 = 19.4% | 6/29 = 20.7% |
| 竞争 | `10/14 µm` | 53,201 | 7.75% | 22/31 = 71.0% | 5/31 = 16.1% | 5/22 = 22.7% |
| 竞争 | `12/14 µm` | 132,869 | 19.37% | 26/31 = 83.9% | 5/31 = 16.1% | 5/26 = 19.2% |
| 竞争 | `16/14 µm` | 364,096 | 53.07% | 29/31 = 93.5% | 5/31 = 16.1% | 5/29 = 17.2% |

关键对照是 `16/20 µm`：基础排序只有 `2/31`，竞争排序 `3/31`；而 `16/14 µm` 分别达到 `6/31` 和 `5/31`。因此主要收益来自去掉 daughter 间距过大的组合，而不是继续增加 parent 距离范围。

在基础排序下，`10/14`、`12/14`、`14/14`、`16/14` 的 Top-1 都是 `6/31`，说明 parent 门限从 10 放宽到 16 没有增加当前排序能排到第一的事件，只是逐步恢复了更多真实候选。`10/14` 是最激进的精度优先点，`12/14` 是保留更多召回的折中点。

过度收紧会直接丢失真实候选：`8/14` 只保留 `16/31` 个真实三元组，Top-1 降到 `5/31`；daughter 门限收紧到 `10/12 µm` 时，真实候选召回和 Top-1 都进一步下降。相反，daughter 门限放宽到 `20 µm` 会让候选数和干扰显著增加，Top-1 降到 `2/31`（基础）或 `3/31`（竞争）。

## 3. 结论

1. 用户提出的“精度优先、不要强求所有 parent-daughter 都进入候选池”的方向得到候选层支持。候选池缩小约 92% 后，基础排序 Top-1 从 `2/31` 提升到 `6/31`。
2. 当前最有信息量的门限不是最大召回 `16/20 µm`，而是 daughter-daughter `14 µm`。parent 门限主要控制召回/候选规模，不能单独解决排序错误。
3. 下一阶段若要接入结构选择器，优先比较 `10/14` 与 `12/14`：前者候选最少，后者少丢 4 个真实事件；`16/14` 可作为高召回对照。不得直接把这三个门限的候选层 Top-1 当作 CV 或 LB。
4. `continuation_conflict` 在 `14 µm` daughter 门限下为 `5/31`，没有超过基础排序 `6/31`，但仍可作为结构选择的软特征，不能据此做全局硬筛选。

## 4. EXP037–039 三轮路线复盘

### 最近三轮输出核对

- EXP037：软父体聚合和 FOCUS3D 掩膜作为统一排序特征，Top-1 仍为 `2/31`；掩膜只改善部分名次，事件级胜负不稳定。
- EXP038：continuation/parent 竞争 Top-1 为 `3/31`，较基础增加 1 个；叠加 FOCUS3D 掩膜反而降到 `1/31`，说明掩膜不能全局线性加权。
- EXP039：固定上述排序器，只扫距离门限；daughter `20→14 µm` 后候选量大幅下降，基础 Top-1 达到 `6/31`，证明此前确实在候选噪声中工作。

### 是否跑偏

路线没有偏离已确认瓶颈：EXP033 已证明真实三元组可以全部进入最大池，EXP039 进一步证明主要问题是候选组合爆炸和错误竞争，而不是继续训练 verifier。当前仍应围绕候选门控与结构联合选择推进，不应回到合成 division 分类器或全局 FOCUS3D 线性加权。

### 受约束头脑风暴

**方向 A：候选生成层（部分已验证，下一步可做）**

- 已试过：`16/20 µm` 最大召回池、简单 parent/daughter 距离扫描、parent 软证据、FOCUS3D 全局几何加权。
- 尚未试过：将 `12/14` 或 `10/14` 作为实际候选门接入完整结构选择器，并保留一个“被门限拒绝的候选”回退通道；这样能验证候选压缩是否能迁移到全局图，而不只是在正事件面板上提升 Top-1。

**方向 B：结构联合选择层（尚未完成）**

- 已试过：单个三元组排序、continuation 冲突软分数；没有完成生产图上的 parent 唯一、daughter 唯一、无 division 选项和普通 continuation 的联合优化。
- 尚未试过：固定 `14 µm` daughter 门后，把 division 作为可选结构，与 continuation 和 no-division 共同竞争；重点记录被门限删除的事件、被普通边占用的事件以及最终 fork 的 FP/TP 变化。

**方向 C：官方评测层（必须补齐）**

- 尚未完成：将门限方案接入完整测试电影，用官方 patched scorer 做 CV/提交验证，并保留无 division transition 以衡量误报代价。
- 候选层 31 个正事件的结果只能做方向筛选，不能证明 LB 提升。

## 5. 保留/暂停/放弃

- **保留**：daughter-daughter `14 µm` 门；`12/14` 作为下一轮默认折中，`10/14` 作为精度优先对照；continuation/parent 竞争作为软特征。
- **暂停**：FOCUS3D 掩膜的全局线性加权；继续扩大 `16/20 µm` 候选池。
- **放弃**：在没有真实候选召回证据的情况下继续优化合成 division verifier；把候选层 Top-k 或 proxy 分数当作正式 CV。

## 6. 实验限制

本轮没有官方 CV、没有 LB、没有 submission。候选门限是在同一批 31 个正事件上筛选，存在门限过拟合风险；下一轮必须采用独立视频留出或完整官方 scorer 验证，并同时包含无 division transition。
