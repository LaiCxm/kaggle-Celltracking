# EXP056：Edge 保护版 cos060

EXP049 的 cos060 在四个完整视频上达到 division TP/FP/FN=2/0/3，且普通 Edge
分数没有下降。本实验以该分支为唯一基准，增加一个局部 Edge 保护门：

- 不扩展 Top-k；
- 不放宽 division 几何门；
- 不使用 EXP054 的联合后置选择；
- 只在后 ILP 分裂候选会替换一个已有入边时检查被替换边；
- 如果旧边有明显更高的模型置信度，拒绝本次重连；
- 旧边没有可用置信度时，只使用有限的距离保护，不把缺失值当成低置信度；
- 不新增合成节点，接受后的 fork 不再交给其他 division 选择器改写。

Notebook 同时运行三臂：

1. off：1/0/4 对照；
2. exp049_cos060：原始 2/0/3 基准；
3. exp056_edge_protected：本实验唯一改动。

正式判断使用官方 patched scorer，重点观察 division 是否保持 2/0/3、调整后 Edge 是否
不下降，以及保护门实际拒绝了多少候选。通过后才考虑制作隐藏测试提交版。
