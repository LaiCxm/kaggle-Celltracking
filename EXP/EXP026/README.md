# EXP026：分裂候选几何门召回—预算扫描

EXP025 在 18 个真实分裂事件上匹配了全部父/子端点，但 14 微米父子门和双子间距门只保留 14 个正确三元组。EXP026 固定同一批视频和事件，先用 32 微米上限生成一次候选超集，再离线回放完整几何门网格。

预注册门限：父子门和双子间距门均取 `14, 16, 18, 20, 24, 28, 32` 微米，共 49 个组合。

选择规则：

1. 必须召回本轮全部 18 个真实分裂三元组；
2. 在满足完整召回的组合中，选择候选总数最少者；
3. 若候选数相同，依次选择最大半径更小、半径和更小、父子门更小的组合；
4. 若 32 微米仍不能完整召回，则不自动选择门限，只报告失败事件。

本实验只诊断候选召回与候选数量膨胀，不训练排序器、不生成最终图、不运行官方完整电影 CV，也不生成 `submission.csv`。
